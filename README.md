# Microsoft App Icons

A curated collection of Microsoft application and service icons in SVG format, maintained by Brandon Pittman. Browse and download individual icons without a Figma account.

**[Browse the icon catalog](icons/README.md)** · **[Download all icons](https://github.com/quantumfctn/MSFT-Icons/archive/refs/heads/main.zip)** · **[View the Figma collection](https://www.figma.com/design/Dc9hrEER6fgmrXVmOIImJT/Microsoft-App-Icons?node-id=0-1)**

## The collection

- **[Current icons](icons/icons--0-1):** icons from the main collection.
- **[Archive](icons/archive--686-155):** deprecated icons preserved for older products and projects.

The visual catalog includes previews, SVG downloads, and links to each icon in Figma.

## Downloading icons

Open the [catalog](icons/README.md), select an icon's name, and use GitHub's **Download raw file** button to save its SVG. To download the entire collection, use the ZIP link above or **Code → Download ZIP**.

SVG files can be imported into design tools or used in documentation, presentations, and diagrams. Some SVGs include embedded raster imagery; these are marked **Includes raster image** in the catalog.

For tools and integrations, the [JSON index](icons/index.json) lists each icon's name, collection, file path, source link, checksum, and whether it contains raster imagery. Filenames include an identifier to distinguish icons that share a name.
